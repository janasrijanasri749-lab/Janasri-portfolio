Featured Project

Applied computer vision and machine learning, built independently.

Virtual Mouse for Physically Challenged Users

A hands-free, camera-based mouse that lets users with limited physical mobility control a cursor using tracked hand and eye movement — no physical input device required. Built end-to-end, from real-time video capture through gesture classification to cursor control.

Problem

Standard mice and trackpads assume a level of fine motor control that isn't accessible to everyone. This project explores webcam-based gesture tracking as a low-cost, hardware-free alternative.

Approach

Used MediaPipe for real-time hand landmark detection, OpenCV for video processing, and trained a CNN alongside an SVM classifier to recognize distinct gestures and map them to mouse actions.

Outcome

A working prototype that translates webcam-tracked hand movement into functional cursor control and clicks, demonstrating accessible, camera-only human-computer interaction.
